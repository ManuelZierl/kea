# Portable crate boundary

AGENTS.md: kea-core is std-only; kea-document depends only on kea-core. In Cargo manifests track top-level or target-qualified normal/dev/build dependency tables line-by-line: any dependency in kea-core is prohibited, and any other than kea-core in kea-document is prohibited. Dev/build dependencies are included because they pull host integration into portable-crate validation. Also detect known host crate paths in source; this is not a Rust name resolver. Inline-table dependencies, including arrays in feature lists, remain in scope. Cargo dependency sub-tables, renamed packages and unfamiliar host path names may escape matching; verify manifests with Cargo metadata when changing them. A standard-library `std::io` use and kea-core workspace dependency are legitimate.
