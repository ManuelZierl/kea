Acceptable: guarded auto-scroll. document_view.rs checks all visible block editors for focus or a nonempty selection before `document_scroll.scroll_to_bottom()`, and the page pin above preserves `page_start` when any visible editor is focused or selected. Scroll runs only when `page_start.is_none()` and no reader is detected, so live output cannot yank a reading viewport. New `follow_output_tail` targets only the new editor.
