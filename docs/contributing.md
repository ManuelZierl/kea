# Contributing

Bug reports, documentation, real-desktop testing and code contributions are welcome.
Read the [contributor guide on GitHub](https://github.com/ManuelZierl/kea/blob/main/CONTRIBUTING.md)
for setup, checks and pull-request guidance. Branch from and open PRs against
`develop`; `main` holds release-ready changes.

- [Desktop testing checklist](manual-testing.md)
- [Architecture](architecture.md)
- [Roadmap](roadmap.md)
- [Code of Conduct](https://github.com/ManuelZierl/kea/blob/main/CODE_OF_CONDUCT.md)
- [Security policy](https://github.com/ManuelZierl/kea/blob/main/SECURITY.md)
